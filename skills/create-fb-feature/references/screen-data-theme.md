# 大屏数据、图表与资源

**何时读**：涉及图表、接口、轮询、地图、视频或实时连接。先选实际拥有者和生命周期，而不是根据 tag 前缀猜 API。

## 数据与图表

大屏可能通过 common-libs + 当前入口 generator 组合 `$svc`；复用实际共享服务，不发明跨代命名空间。响应和字段按本次接口契约，空数据/失败不伪报成功。

已观察 fbec-* 包装通过 ref.updateOptions 更新，内部 FbEcharts 在 beforeDestroy destroy/dispose。**销毁不是 autoresize 开关的附带效果**，autoresize 只与尺寸响应相关；具体实现仍核对当前包。

可以复用合法包装，也可以为新图表显式初始化 ECharts：拥有者负责实例复用、尺寸监听、切主题、dispose 和事件移除。不能因为“裸 init”就自动认作缺陷。resize 回调、隐藏恢复、数据更新/空态都测试。

## 定时与异步

Timer mixin 只有在目标已存在且清理正确时复用。自行 setInterval/setTimeout 也可，但记录并卸载清理；轮询避免请求重叠，切页后迟到响应不写旧组件。onHide/visibility 是否暂停依据运行环境和需求。

WebSocket/SSE、外层延时、resize/event bus 监听均与生命周期配对，卸载后用相同函数引用移除。组件包装已管理的资源不重复销毁。

## 地图与播放器

地图/视频 API 从安装源码/实际注册确认，按 owner/版本处理，不借其他插件的方法。场景选择 Mars3D、Leaflet、Three 或平台播放器以目标可用包和需求决定；缺依赖时明确不可验证，不装一个近似库凑数。

检查实例、图层、marker、渲染 loop、监听与播放连接的拥有者/退出，隐藏不等于停止。密钥/认证不抄样本长效 token，截图/日志/档案不暴露秘密；公开客户端配置不能保密。

## Mock 与验收

接口未就绪时使用明确隔离的 mock fixture/服务并标 mock 模式，保留接口待办。没有真实请求就不能称联调成功。

验收包括数据刷新、重复请求/迟到响应、空/错状态、主题/resize、路由卸载和监听/资源释放。模板编译只证明语法层，不证明播放器/地图/实时接口可用。
